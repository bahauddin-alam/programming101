# Programming 101 questions

**The plan:**

1. Hello world, print your name and details, multi-line output with `console.log`
2. `let`/`const`, template literals, input via `readline`, swap two variables, greet a user
3. Operators: sum/average, area of circle, simple interest, °C to °F
4. Strings: `trim`, `slice`, `includes`, `replace`, `split`/`join`, and getting initials from a name
5. `if / else if / else`: even/odd, positive/negative, voting eligibility
6. Leap year, largest of 3, grade calculator, calculator with `switch`
7. `for` loops: 1 to N, even numbers, multiplication table, sum of 1 to N
8. `while` loops: count digits, sum of digits, reverse a number, countdown
9. Nested loops: star triangle, pyramid, number patterns, diamond
10. Arrays: create, access, loop, sum, `push`/`pop`
11. `shift`, `splice`, `slice`, `indexOf`, then double each item, filter evens
12. Linear search, max, min, sum, second largest
13. `Set` and destructuring: unique elements, common elements of two arrays, swap with destructuring
14. Objects: student record, phone book lookup, update and delete keys
15. Frequency counting: characters, words, most repeated element
16. Functions: declare, call, `isEven`, `add`, `greet`
17. Parameters, default values, return, arrow functions
18. Break a problem into functions: grade report, number analyzer
19. String problems: reverse, palindrome, count vowels
20. Prime check, factorial, Fibonacci
21. Built-ins: `Math.random`, `Math.max`, `sort`, `Date`, dice roller, days until a date
22. `map`, `filter`, `reduce`: squares, long words only, sum with `reduce`
23. Files with `fs`: read a file, count lines/words, write notes
24. `try/catch`: safe division, safe `JSON.parse`, input validation loop
25. Modules: `import`/`export`, write your own math module, use one npm package
26. **Mini project 1:** CLI to-do list or expense tracker
27. **Mini project 2:** menu-driven ATM or contact book
28. Marathon: FizzBuzz, GCD, Armstrong, anagram, decimal to binary, and a few more
29. Redo 3 old problems from scratch using only the universal pattern
30. Final challenge, then your roadmap: DOM, async/`fetch`, then a real project

You already know some JS, so you can double up and finish in about 15 days. Don't skip days 7 to 9 and 19 to 20, because the loop and logic muscle comes from those.
